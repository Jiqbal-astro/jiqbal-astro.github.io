JAVED IQBAL — ACADEMIC ASTRONOMY WEBSITE

Files for GitHub Pages. Every page shares one white theme: Times New Roman for the text, Lato for the menu
and small buttons, soft blue accents, and the same header, navigation and footer.

FILES
- style.css ............ shared theme for ALL pages (must be uploaded with the HTML files)
- index.html ........... home / about / contact
- research.html, full-publications.html, tools.html, outreach.html
- publications.html .... redirects to full-publications.html
- projects.html ........ redirects to tools.html (keeps old links working)
- profile.jpg, cv.pdf

EDITING
- To change colours or fonts site-wide, edit the variables at the top of style.css.
- Each section on the inner pages is a <section class="row"> with the heading on the left
  and content on the right; copy an existing block to add a new one.

PUBLISHING
1. Extract this archive.
2. Upload the contents of this folder to the root of your GitHub Pages repository
   (keep style.css next to the HTML files).
3. Commit and push to the branch configured for GitHub Pages.
